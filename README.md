# Complete Guide: Self-Hosted RustDesk Server

*Complete installation and configuration from scratch with DDNS domain, Docker, Port Forwarding, and Environment Variables.*

* **Local Server IP:** `192.168.X.X`
* **Virtual Switch:** Bridged Adapter
* **Docker Stack:** `hbbs` & `hbbr`
* **External Domain (DDNS):** `example-name.duckdns.org`
* **Required Ports:**
* `21115` (TCP)
* `21116` (TCP & UDP)
* `21117` (TCP)
* `21118` (TCP)
* `21119` (TCP)

## Step 1: VirtualBox and Network Configuration (Bridged)

1. **Create VM:** Open VirtualBox, click *New*, name it whatever you want, and select the Ubuntu Server ISO image. Allocate at least 2GB RAM, 2 CPU cores, and a minimum 20GB disk.
2. **Adapter Configuration:** Go to Settings → *Network* → *Adapter 1*. Check *Enable Network Adapter* and set *Attached to: Bridged Adapter*. Under *Name*, select your active physical network card (Wi-Fi or Ethernet).


## Step 2: Ubuntu Server Installation & VS Code Connection

1. Power on the virtual machine, follow the installation steps, leave the network on DHCP (it will acquire an IP via Bridge), and make sure to check the **OpenSSH server** package for remote access.
2. Connect via SSH from VS Code or PowerShell using the assigned IP:
```bash
ssh user@192.168.X.X
```

## Step 3: Setting a Static Local IP (DHCP Binding)

1. Access your router's panel (e.g., gateway address, usually `x.x.1.1`).
2. Go to *Network* → *LAN* → *DHCP Binding* (or *Static DHCP*).
3. Bind the MAC address of the virtual machine to your chosen permanent static IP.

## Step 4: Configuring DDNS (DuckDNS or Alternatives)

To ensure your public IP (which can change from your ISP) remains reachable via a fixed name:

1. Create an account on [DuckDNS](https://www.duckdns.org) and generate a subdomain (e.g., `example-name`).
2. On the virtual machine, create the dedicated folder and update script:
```bash
mkdir -p ~/duckdns
nano ~/duckdns/duck.sh
```

3. Add the lines below (replacing with your real details):
```bash
#!/bin/bash
curl -k -s "https://www.duckdns.org/update?domains=example-name&token=YOUR_TOKEN_HERE" -o ~/duckdns/duck.log

```

4. Set permissions and automation in `crontab` (every 5 minutes):
```bash
chmod 700 ~/duckdns/duck.sh
crontab -e

```
Add the following line at the end of the file:
```text
*/5 * * * * ~/duckdns/duck.sh >/dev/null 2>&1

```

## Step 5: Installing Docker and Project Structure

1. Install Docker on Ubuntu:
```bash
sudo apt update && sudo apt install -y docker.io docker-compose-v2
sudo usermod -aG docker $USER && newgrp docker

```


2. Create the project directory:
```bash
mkdir -p ~/rustdesk-server/secrets && cd ~/rustdesk-server

```


3. **Creating the `.env` file (for secrets and configurations):**
Create the `.env` file with a template such as:
```env
RUSTDESK_RELAY_DOMAIN=example-name.duckdns.org
```


4. **Creating the corrected `docker-compose.yml` file:**
```yaml
services:
  hbbs:
    container_name: hbbs
    image: rustdesk/rustdesk-server:latest
    command: hbbs -r ${RUSTDESK_RELAY_DOMAIN}
    volumes:
      - ./secrets:/root
    ports:
      - "21115:21115"
      - "21116:21116"
      - "21116:21116/udp"
      - "21117:21117"
    restart: unless-stopped

  hbbr:
    container_name: hbbr
    image: rustdesk/rustdesk-server:latest
    command: hbbr
    volumes:
      - ./secrets:/root
    ports:
      - "21118:21118"
      - "21119:21119"
    restart: unless-stopped

```

## Step 6: Startup and Port Forwarding in Router

1. Start the containers (which will automatically generate the keys inside the `secrets` folder):
```bash
docker compose down && docker compose up -d

```

2. **Port Forwarding (in your router's interface):** Forward the following ports to the virtual machine's internal IP:
* Port **21115** (TCP) ➔ `192.168.X.X`
* Port **21116** (TCP) ➔ `192.168.X.X`
* Port **21116** (UDP) ➔ `192.168.X.X` 
* Port **21117** (TCP) ➔ `192.168.X.X`
* Port **21118** (TCP) ➔ `192.168.X.X`
* Port **21119** (TCP) ➔ `192.168.X.X`

## Alternative DDNS Services

Besides DuckDNS, you can use other Dynamic DNS platforms:

1. **No-IP (noip.com):** Offers free domains like `name.ddns.net` and provides update clients for Linux.
2. **Dynu (dynu.com):** Stable service with an HTTP GET API, easily integrated into similar bash scripts.
3. **Cloudflare (with your own domain):** Automated updates via API using a custom cron script.

## Step 7: Retrieving the Key and Client Testing

1. Display the public key generated by the server to provide it to clients:
```bash
cat ~/rustdesk-server/secrets/id_ed25519.pub

```
2. **Testing:** On a mobile device (using mobile data, with Wi-Fi turned off) or another external computer, open the RustDesk app → *Settings* → *Network* → *ID/Relay server*:
* **ID server:** `example-name.duckdns.org`
* **Key:** (The long string obtained from the previous command)
